Debugging ⭐ Most Requested

Error Search & Fixing in Power BI / Power Query

Finding the root cause behind wrong numbers and refresh failures in Power Query and DAX, then fixing the logic without breaking the rest of the model.

Business challenge A production dataflow started returning incorrect prices for one analysis category, and a separate Power BI model failed to refresh with "Cannot find table" and null-to-text conversion errors — blocking reporting until resolved.
Root cause Three unrelated issues traced in parallel: a query referencing the wrong list/table object for a branch lookup, a DAX measure pointing to a table name no longer in the model, and a cleaning step that failed on blank (null) cells instead of skipping them.
Solution
  • Diagnosed each refresh error using detailed error messages and cell inspection
  • Traced the pricing discrepancy to a mismatched list reference and corrected it
  • Rebuilt null-handling so empty cells pass through safely instead of breaking refresh
  • Verified every fix against real order-level data before deployment
Business outcome
  • Restored accurate category-level pricing in the dataflow
  • Eliminated refresh failures from missing tables and null values
  • Documented each root cause to reduce recurrence risk
  • Increased confidence in report numbers before they reach stakeholders
