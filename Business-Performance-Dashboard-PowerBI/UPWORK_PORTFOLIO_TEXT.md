# Upwork Portfolio Entry

## Title
Business Performance Dashboard | Power BI, DAX, SQL

## Short description
Built an interactive Power BI dashboard for management reporting using a star-schema data model. Created DAX measures for revenue, profit, margin, order volume, average order value and year-over-year growth. Added regional, customer and product-level analysis with interactive filters and clear KPI views.

The project demonstrates an end-to-end BI workflow: source data preparation, data modeling, KPI logic, visualization and validation.
