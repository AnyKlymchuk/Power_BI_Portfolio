## Upwork portfolio entry

**Title:** Monthly Bank Reconciliation with Python

**Role:** Python developer and financial data analyst

**Description:**

I built a Python portfolio project that compares a monthly bank statement with an internal cash ledger from another system. It identifies missing transactions, repeated references, amount differences, posting-date differences and fee discrepancies. The solution preserves source transaction IDs and checks account balances and source row counts.

The deliverables include a reconciliation algorithm, synthetic CSV data, exception reports, automated tests, and an interactive offline dashboard. I also prepared a Power BI build guide. Ambiguous matches remain available for review rather than being approved automatically.

**Skills to select when available:** Python, Bank Reconciliation, Data Cleaning, Financial Analysis, Data Visualization.

**Attachments:** dashboard screenshot, dashboard.html, README, and a link to the reviewed GitHub project. Label the browser dashboard accurately; do not claim it is a Power BI file.

## Upwork service / Fiverr gig

**Title:** I will automate monthly bank reconciliation with Python

**Description:**

I help finance teams compare bank statements with internal ledger exports and investigate reconciliation differences.

I can prepare a Python workflow to validate your files, match transactions using agreed rules, identify missing or repeated items, compare amounts and fees, and export a clear exception report. A dashboard can show account balances, unresolved differences and items requiring review.

Please provide anonymized sample exports and explain your account mapping, date rules, references, sign convention and expected result. I will confirm the scope before work begins. Source-system corrections and accounting approvals remain with your authorized team.

**Suggested initial scope:** one bank CSV, one ledger CSV, one month, one account/currency, agreed one-to-one reference matching, exception CSV, reproducible Python script and handover notes. Quote after inspecting sample formats; no arbitrary delivery/performance guarantee.

**Optional larger scope:** multiple accounts, dashboard, fee-rule mapping, scheduled local execution, Power BI implementation or SQL matching. Estimate separately.

**Client intake questions:**

1. What does each system record, and which cash accounts should be compared?
2. Can you provide anonymized exports with stable transaction IDs and shared references?
3. Are positive/negative amounts defined the same way in both systems?
4. Which dates determine the reporting month? How are cross-month items handled?
5. Are settlements one-to-one or aggregated? Are fees included in the net payment?
6. What independent counts/balances confirm complete exports?
7. Who investigates and approves exceptions? What output do they need?
